# mern_stack

Express & Node.js: 
Handles your server-side logic and API endpoints. 
You can connect this with a database (like MongoDB) to create, read, update, or delete data.

MongoDB with Mongoose:
Manages your database. Using Mongoose,
you can easily define models (schemas) and perform CRUD operations in a structured way.

React: 
Renders the frontend. React components fetch data from your Express API and display it to the user. 
The interaction is done through HTTP requests (using fetch or Axios).
